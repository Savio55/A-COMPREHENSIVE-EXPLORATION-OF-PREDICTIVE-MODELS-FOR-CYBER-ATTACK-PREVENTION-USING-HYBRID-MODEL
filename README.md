# Cyber Attack Prevention Using Hybrid Models

## Objective

Develop predictive models for cyber attack detection
using machine learning and deep learning approaches.

## Dataset

CICIDS2017

## Models Used

- Logistic Regression
- Random Forest + ANN
- Graph Neural Network

## Technologies

- Python
- TensorFlow
- Scikit-Learn
- Pandas
- NumPy

## Results

Achieved high performance in detecting malicious traffic
with improved prediction capabilities.
